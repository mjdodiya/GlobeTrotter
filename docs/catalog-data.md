# Catalog data provenance

The initial catalog is an original development dataset maintained in `packages/db/src/seeds/catalog.ts`. Coordinates and IANA time-zone identifiers describe well-known cities; activity descriptions are original GlobeTrotter copy, and all activity costs are synthetic planning estimates dated in the seed file rather than quoted prices.

No third-party photographs are bundled or hotlinked. The web application uses code-native destination art treatments until individually licensed images and their attribution records are added here.
